# v1.0.1

Same product as 1.0.0. This build exists so that what is published matches the recorded
code exactly — the 1.0.0 installer was built a moment before its last fix was written into
the history, so the two did not line up. Nothing about the app itself has changed.

Install this one instead of 1.0.0. If you have already installed 1.0.0, it will offer you
this update the normal way; there is no hurry and nothing will look different.

## For the record

- The POS bill calculations were moved into a file of their own so that the billing screen
  no longer pulls server-side code into the browser. This was already inside the 1.0.0
  installer you were given; only the record of it was missing.
