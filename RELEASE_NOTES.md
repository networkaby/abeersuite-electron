# v1.16.2

A small fix for the WhatsApp Inbox. Install it when the counter is quiet — there is no hurry and it will not interrupt a sale.

## WhatsApp Inbox
- **Mobile app Inbox now stays on for the right staff.** The Inbox, Photos and App Access ticks for the Operations and Sales departments were not being kept, so the Inbox could vanish from the phone app. They are fixed now.
- **"Create ticket" now shows for staff who only have the Tickets permission.** Earlier it appeared only if the person also had Help or Deals permission, in the counter Inbox and in the phone app.
- **Counter Inbox panel width fixed.** The Inbox drawer on the billing screen opens at its proper width again.
- **Permission lists now save reliably.** Saving roles and permissions always reads and writes the main database, so a tick you give is not lost.

No database change in this release.
