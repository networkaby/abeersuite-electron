Makers (e.g. Portronics) use one box for every colour variant, so the box picture or a "Colour: Grey" line does not prove the unit inside is that colour. Never raise a pending/staff line because product photos show a different colour than the box.

**Why:** owner, 2026-11-23, on SKU 486949 (Mport 31C) — my Part 4 line "photos show black, box says Grey" was wrong; owner set it aside and asked to remove it.

**How to apply:** check colour only against our own unit photos; a colour doubt goes to the report for the owner, never to Attention. Related: [feedback_shipping_never_blocks_prep](feedback_shipping_never_blocks_prep.md).
